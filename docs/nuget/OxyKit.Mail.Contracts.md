# OxyKit.Mail.Contracts

Shared send request/response DTOs for OxyKit.Mail (API key / integrator surface).

Integrators normally take [`OxyKit.Mail.Client`](https://www.nuget.org/packages/OxyKit.Mail.Client) only; this package is pulled in transitively.

Docs: [oxykit.dev](https://oxykit.dev) · Source: [oxykit-dev/OxyKit.Mail](https://github.com/oxykit-dev/OxyKit.Mail)
